**The Velvet Hour** — a top-down stealth game about a museum heist. You are a thief
working three galleries after dark: lift every gem, then slip out the exit without
ever being seen. Guards patrol with vision cones that are clipped by walls, crates,
statues and display cases, so cover is real — and shadow floors hide you while lit
floors expose you. Sneak with Shift, toss a coin with Space (or right-click) to pull
a guard off his patrol, and watch the suspicion meter: a full meter means a chase,
and a caught thief ends the night.

Three levels — The Marble Hall, The Gilded Wing, The Vault Below — with more guards,
longer sight lines and less light as the night goes on. Score comes from gems plus a
time bonus against each gallery's par time. Keyboard and mouse, touch drag to steer
on mobile, synthesized sound effects (WebAudio, no files), fully offline static
files with no build step.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 in a desktop browser
```

WASD / arrows move · click to walk there · Shift sneak · Space / right-click tosses
a coin · P pause · M mute · R restart the level.
